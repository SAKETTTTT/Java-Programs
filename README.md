# Java Programs

Small practice programs written while learning Java, one concept per file. Every file is a standalone program with its own `main` method.

## Run one

You need a JDK (Java 8 or newer).

```bash
javac Program03.java
java Program03
```

Most programs ask for input in the terminal.
